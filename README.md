# 3D 文物展｜瓯韵千年·蕨影流光

这是一个以温州博物馆馆藏的**北宋瓯窑青釉褐彩蕨草纹执壶**为主题的 AI 赋能研学项目。

## 项目简介

本项目计划通过互动式网页，让参观者了解瓯窑文化和家乡文物。

计划包含的功能：
- 360° 旋转观察文物，并支持放大、缩小和自动旋转
- 中文语音讲解与文物知识介绍
- 宝塔形壶盖、褐彩蕨草纹、曲柄与“七何”铭文观察点
- “素胎—青釉褐彩”数字工艺演示
- 5 道互动知识问答、自动评分和错题回顾

## 当前进度

本仓库目前为**初始版本，仅包含 README.md**。3D 网页尚未上传，GitHub Pages 尚未开启。

## 下一步：发布网页

1. 将完成的 3D 文物展 HTML 文件重命名为 `index.html`。
2. 将 `index.html` 提交到本仓库的 `main` 分支。
3. 进入 **Settings → Pages**，选择 **Deploy from a branch**，部署 `main` 分支的 `/(root)` 目录。
4. 通过 GitHub Pages 生成的网址测试电脑及手机端的功能。
