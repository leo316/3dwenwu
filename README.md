# 3D 文物展｜瓯韵千年·蕨影流光

以温州博物馆馆藏**北宋瓯窑青釉褐彩蕨草纹执壶**为主题的 AI 赋能研学项目，适合文物观察、数字文化体验和知识互动学习。

## 在线展厅

网页源文件：[index.html](./index.html)

**GitHub Pages 启用后，展厅网址预计为：** https://leo316.github.io/3dwenwu/

目前已将网页完整提交到 `main` 分支。若上述地址尚不能打开，请按下方步骤启用 GitHub Pages。

## 互动功能

- 360°观察执壶、缩放及自动旋转
- 中文语音导览（音频内嵌，支持离线使用）
- 宝塔形壶盖、褐彩蕨草纹、曲柄与“七何”铭文观察点
- “素胎—青釉褐彩”数字工艺演示
- 5道互动知识问答、自动评分与错题回顾
- 手机与电脑浏览器适配

## 启用 GitHub Pages

1. 打开本仓库 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. Branch 选择 **main**，目录选择 **/(root)**。
4. 点击 **Save**，等待 GitHub Pages 显示网站地址。
5. 访问 https://leo316.github.io/3dwenwu/ 检查交互、中文语音和手机显示。
